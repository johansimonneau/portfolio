Librairie MCP Marketing

Connecter GitHub en MCP à Claude ou ChatGPT

GitHub propose deux façons officielles de se connecter en MCP : un serveur distant qu'il héberge lui-même, ou un conteneur Docker en local. Voici les deux options.

Le serveur MCP officiel de GitHub permet de lire des dépôts, gérer des issues et pull requests, et suivre des workflows CI/CD directement en langage naturel — utile dès que votre site ou vos landing pages sont versionnés.

Statut & type de connexion

Éditeur
GitHub
Statut
Officiel
Connexion
Distante (recommandée) ou locale (Docker)

Option recommandée : serveur distant hébergé par GitHub

URL du serveur officiel :

https://api.githubcopilot.com/mcp/

Exemple de déclaration officiellement documenté (format VS Code, adaptable à d'autres clients) :

{
  "servers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/"
    }
  }
}

Option locale : conteneur Docker

Pour un usage local plutôt que distant, GitHub documente aussi une image Docker officielle. La configuration exacte (variables d'environnement, port, mode d'authentification par jeton d'accès personnel via la variable GITHUB_PERSONAL_ACCESS_TOKEN, ou par GitHub App) est détaillée sur le dépôt officiel — reportez-vous-y avant de choisir cette option, les options changent régulièrement.

Authentification

OAuth (flux dans le navigateur, recommandé) ou jeton d'accès personnel (GITHUB_PERSONAL_ACCESS_TOKEN) pour un usage local ou non interactif ; une GitHub App est aussi documentée pour les usages automatisés.

Documentation officielle

github.com/github/github-mcp-server

FAQ

Vaut-il mieux utiliser le serveur distant ou l'option Docker locale ?

Le serveur distant hébergé par GitHub est l'option recommandée pour la plupart des usages, sans rien à maintenir. L'option Docker locale reste utile pour des besoins spécifiques d'isolation ou de réseau.

Un jeton d'accès personnel suffit-il, sans OAuth ?

Oui pour un usage local ou non interactif, un jeton d'accès personnel (GITHUB_PERSONAL_ACCESS_TOKEN) fonctionne ; OAuth reste le flux recommandé pour un usage interactif.

Ce connecteur donne-t-il accès à tous mes dépôts par défaut ?

L'accès dépend des permissions accordées lors de l'authentification (OAuth, jeton ou GitHub App) — consultez la documentation officielle pour restreindre l'accès aux dépôts nécessaires.
