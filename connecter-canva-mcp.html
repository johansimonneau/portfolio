Librairie MCP Marketing

Connecter Canva en MCP à Claude ou ChatGPT

Canva héberge un serveur MCP officiel pour générer, éditer et exporter des designs directement depuis votre assistant IA. Voici comment l'ajouter.

Le serveur MCP officiel de Canva permet de rechercher, générer, éditer et exporter des designs depuis un assistant IA compatible, sans quitter la conversation.

Comment se connecter

URL du serveur officiel :

https://mcp.canva.com/mcp

Avec Claude Code (ligne de commande) :

claude mcp add canva --transport http https://mcp.canva.com/mcp

Avec un client à interface graphique : ajoutez un connecteur personnalisé dans les réglages et collez cette URL.

Attention à ne pas confondre ce serveur (plateforme de design Canva) avec le « Dev MCP server » distinct, documenté séparément par Canva pour les développeurs qui construisent des applications Canva.

Authentification

OAuth : à la première connexion, votre client IA ouvre une fenêtre de connexion Canva, puis réutilise les identifiants obtenus pour les sessions suivantes.

Documentation officielle

canva.dev/docs/apps/mcp

FAQ

Ce connecteur peut-il créer un design de A à Z ?

La documentation officielle décrit des capacités de génération, édition, gestion d'assets et export de designs — le niveau de contrôle exact dépend des outils exposés par le serveur, détaillés dans la doc officielle.

Faut-il distinguer le serveur MCP Canva grand public du Dev MCP server ?

Oui, ce sont deux serveurs distincts : celui de cette page sert à utiliser Canva depuis un assistant IA, l'autre sert aux développeurs qui construisent des applications Canva.

Un compte Canva gratuit suffit-il ?

L'accès exact selon les formules Canva (gratuit ou payant) est détaillé dans la documentation officielle liée ci-dessus.
