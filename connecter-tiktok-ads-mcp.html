Librairie MCP Marketing

Connecter TikTok Ads en MCP

TikTok héberge son propre serveur MCP officiel pour les campagnes publicitaires : deux variantes au choix selon votre client IA. Voici comment l'ajouter.

Le serveur MCP officiel de TikTok for Business donne accès à la gestion de campagnes, au reporting de performance, à la configuration d'audiences et aux opérations créatives directement depuis un assistant IA compatible, sans installation locale.

Comment se connecter

Deux URLs officielles, selon le profil de votre client IA :

https://business-api.tiktok.com/open_mcp/tt-ads-mcp-flat

La variante « flat » charge d'un coup l'ensemble des outils (environ 400) — c'est celle que TikTok recommande pour Claude, qui gère bien un grand nombre d'outils disponibles.

https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer

La variante « layer » ne charge qu'une quarantaine d'outils essentiels au départ, le reste étant découvert à la demande — utile pour un client à fenêtre de contexte plus limitée.

Dans les réglages de connecteurs de votre client IA (Claude, ChatGPT...), ajoutez un connecteur personnalisé et collez l'URL choisie.

Authentification

Connexion via votre compte TikTok for Business (OAuth). Pas de création d'app développeur ni de gestion de clé API nécessaire pour cet usage : le protocole MCP gère l'authentification directement.

Documentation officielle

ads.tiktok.com

FAQ

Quelle URL utiliser, flat ou layer ?

TikTok recommande l'URL « flat » (tous les outils chargés d'un coup) pour Claude, qui gère bien un grand nombre d'outils. L'URL « layer » (outils chargés progressivement) convient mieux à un client avec une fenêtre de contexte plus limitée.

Faut-il un compte développeur TikTok for Business pour l'utiliser ?

Non, la documentation officielle indique qu'un compte TikTok for Business standard suffit, avec une connexion OAuth directe — pas de création d'app ni de gestion de clé API nécessaire pour cet usage.

Ce connecteur permet-il seulement de consulter les données, ou aussi de gérer les campagnes ?

Les deux : la documentation officielle couvre à la fois le reporting de performance et des actions de gestion (campagnes, audiences, créations). Les permissions suivent celles de votre compte TikTok for Business — vérifiez les accès avant de connecter un agent IA avec droits d'écriture.
