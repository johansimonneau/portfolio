Librairie MCP Marketing

Connecter Meta Ads (Facebook / Instagram) en MCP

Meta héberge son propre serveur MCP officiel pour les campagnes Facebook et Instagram Ads : une seule URL, identique partout dans le monde. Voici comment l'ajouter.

Le serveur MCP officiel de Meta donne accès à l'API Marketing de Meta (comptes publicitaires Facebook et Instagram) directement depuis un assistant IA compatible, sans installation locale.

Statut & type de connexion

Éditeur
Meta
Statut
Officiel
Connexion
Distante (URL)

Comment se connecter

URL du serveur officiel :

https://mcp.facebook.com/ads

Dans les réglages de connecteurs de votre client IA (Claude, ChatGPT, Cursor...), ajoutez un connecteur personnalisé et collez cette URL. Meta indique que cette URL est identique quel que soit le client ou la région.

Authentification

Connexion via votre compte Facebook (OAuth). L'accès aux comptes publicitaires suit les mêmes règles de permission que l'API Marketing de Meta : vous ne verrez que les comptes auxquels votre compte Facebook a déjà accès.

Documentation officielle

developers.facebook.com

FAQ

L'URL du serveur Meta Ads MCP change-t-elle selon le pays ?

Non, Meta indique que cette URL est identique quel que soit le client ou la région.

Ce connecteur donne-t-il accès à tous les comptes publicitaires Meta existants ?

Non, uniquement aux comptes auxquels votre compte Facebook connecté a déjà accès, selon les mêmes règles de permission que l'API Marketing de Meta.

Faut-il un compte développeur Meta pour l'utiliser ?

La documentation officielle décrit une connexion par compte Facebook standard (OAuth) ; consultez-la pour les cas d'usage avancés nécessitant un accès développeur.
