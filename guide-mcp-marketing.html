1. Qu'est-ce qu'un MCP ?

Le Model Context Protocol (MCP) est un standard ouvert créé par Anthropic fin 2024, aujourd'hui adopté par la plupart des grands éditeurs (Google, Meta, HubSpot, Notion, Figma...). Il définit une façon commune pour un assistant IA de se connecter directement à un outil ou une source de données : plus besoin d'exporter un CSV de Google Analytics ou de copier-coller une liste de contacts HubSpot, l'IA lit (et parfois écrit) directement dans l'outil, avec votre autorisation.

Concrètement, un « serveur MCP » est un petit programme, publié par l'éditeur ou par la communauté, qui fait le pont entre l'outil (GA4, HubSpot, Notion...) et un client compatible MCP (Claude, ChatGPT, Cursor, Gemini...). Cette page ne liste que des serveurs officiels, publiés et maintenus par l'éditeur lui-même — le point de vigilance le plus important quand on connecte ses données marketing à un outil externe.

2. Analytics & mesure

  • Google Analytics (GA4) — serveur officiel publié par Google, en lecture seule : résumés de comptes, rapports standards, funnels, temps réel. Cas d'usage : demander à Claude d'expliquer une baisse de trafic sans ouvrir GA4. Comment le connecter → · dépôt officiel sur GitHub →
  • Google Search Console — Google n'a pas encore publié de serveur MCP officiel pour la Search Console à la date de cette page. Plusieurs projets communautaires existent : à auditer vous-même avant de connecter des données de positionnement, comme n'importe quel code tiers non maintenu par l'éditeur. Le détail →

3. SEO & intelligence concurrentielle

  • Semrush — serveur MCP officiel hébergé par Semrush, authentification par votre compte, aucune installation locale. Cas d'usage : demander une analyse de mots-clés ou un audit concurrentiel directement en conversation. Comment le connecter → · Semrush MCP → (lien affilié : je peux toucher une commission si vous vous abonnez via ce lien, sans coût supplémentaire pour vous)
  • Ahrefs — serveur MCP officiel Ahrefs (à l'origine local, un serveur distant le remplace désormais selon l'éditeur). Cas d'usage : interroger votre profil de backlinks sans quitter votre assistant IA. Comment le connecter → · dépôt officiel →

4. Publicité

  • Google Ads — serveur MCP open source publié par l'équipe Google Ads API, en lecture seule (comptes, rapports GAQL, métadonnées) — pensé pour l'analyse, pas la modification de campagnes. Comment le connecter → · dépôt officiel →
  • Meta Ads (Facebook/Instagram) — serveur MCP officiel hébergé par Meta, avec des règles de permissions qui encadrent ce que l'agent IA peut faire sur un compte publicitaire (budgets, catalogue...). Comment le connecter → · documentation officielle Meta →

5. CRM & automatisation

  • HubSpot — HubSpot publie deux serveurs officiels : un serveur CRM distant (contacts, deals, historique d'échanges) et un serveur développeur pour construire des apps HubSpot. Cas d'usage : interroger l'état d'un deal ou l'historique d'un contact en langage naturel. Comment le connecter → · HubSpot MCP officiel →

6. Productivité & contenu

  • Notion — serveur MCP officiel hébergé par Notion (le serveur auto-hébergé historique n'est plus maintenu, privilégiez la version distante). Recherche, lecture et édition de pages en respectant vos permissions existantes. Comment le connecter → · Notion MCP officiel →
  • Slack — Slack (groupe Salesforce) a publié son propre serveur MCP officiel début 2026, qui remplace l'ancien serveur de référence d'Anthropic — retiré en 2025 après la découverte d'une faille (un message piégé pouvait faire exfiltrer des données via les bots de prévisualisation de liens Slack). Bon rappel : préférez toujours la version officielle la plus récente à un ancien projet abandonné. Comment le connecter → · guide officiel Slack MCP →

7. Design & création

  • Figma — serveur MCP officiel (Dev Mode), pour donner à un agent IA le contexte d'une maquette (composants, variables, auto-layout) ou écrire directement dans un fichier Figma. Comment le connecter → · documentation officielle Figma →
  • Canva — serveur MCP officiel hébergé par Canva : recherche, génération, édition et export de designs directement depuis votre assistant IA. Comment le connecter → · Canva MCP officiel →

8. Code & déploiement

Moins « marketing » au sens strict, mais utile dès que votre site ou vos landing pages sont versionnés :

  • GitHub — serveur MCP officiel GitHub : lecture de dépôts, gestion d'issues et de pull requests, suivi des workflows CI/CD, directement en langage naturel. Comment le connecter → · GitHub MCP Server officiel →

9. Sécurité : ce qu'il faut vérifier avant de connecter un MCP

Un serveur MCP donne à un agent IA un accès plus ou moins large à vos données ou à vos comptes. Quelques réflexes avant de connecter quoi que ce soit :

  • Préférez toujours le serveur officiel de l'éditeur à un projet communautaire non maintenu, surtout pour des données sensibles (CRM, comptes publicitaires, Search Console).
  • Vérifiez le mode d'authentification : un serveur hébergé par l'éditeur en OAuth (Semrush, Notion, Canva, HubSpot...) est généralement plus sûr qu'un script local qui vous demande de coller une clé API en clair dans un fichier de configuration.
  • Limitez les permissions à ce qui est nécessaire : beaucoup de serveurs (Google Analytics, Google Ads) sont volontairement en lecture seule — c'est un choix de sécurité à privilégier tant que vous n'avez pas besoin d'écriture.
  • Ne partagez jamais une clé API dans un outil partagé ou versionné (dépôt Git public, message Slack, document partagé).

Le cas du serveur Slack est un bon rappel : le premier serveur MCP de référence d'Anthropic pour Slack a été retiré en 2025 après la découverte d'une faille de sécurité, avant que Slack ne publie sa propre version officielle début 2026. Un standard ouvert et récent ne veut pas dire que chaque implémentation est sûre : c'est la maintenance et l'audit qui font la différence.

FAQ

Questions fréquentes

Qu'est-ce que le MCP (Model Context Protocol) ?

Un standard ouvert créé par Anthropic qui permet à un assistant IA de se connecter directement à vos outils et données (Google Analytics, un CRM, un espace Notion...) pour répondre à des questions ou exécuter des actions, sans export manuel ni copier-coller.

Est-ce sécurisé de connecter un MCP à mes outils marketing ?

Ça dépend du serveur utilisé. Les serveurs officiels des éditeurs, authentifiés en OAuth et à portée limitée (lecture seule quand c'est suffisant), sont la référence. Les serveurs communautaires non audités présentent plus de risques : vérifiez toujours qui les maintient avant de connecter des données sensibles.

Faut-il être développeur pour utiliser ces connecteurs MCP ?

Pour les serveurs hébergés par l'éditeur (Semrush, Ahrefs, Notion, Canva, Slack), la connexion se fait par une authentification classique, sans compétence technique particulière. Pour certains connecteurs à installer localement, une configuration technique légère est nécessaire.
