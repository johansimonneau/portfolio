Connecter Slack en MCP : le guide officiel

Slack a publié son propre serveur MCP officiel début 2026, qui remplace l'ancien serveur de référence d'Anthropic retiré en 2025 après une faille de sécurité. Voici comment le connecter.

Le serveur MCP officiel de Slack permet à un assistant IA de rechercher des messages et fichiers, lire des canaux et fils, envoyer des messages et consulter des utilisateurs — avec une étape de préparation un peu plus poussée que les autres connecteurs distants de cette librairie.

Comment se connecter

URL du serveur officiel :

https://mcp.slack.com/mcp

Contrairement aux autres connecteurs distants de cette librairie, Slack demande de créer votre propre application Slack au préalable (interne à votre organisation ou publiée sur le Slack Marketplace), avec les permissions (scopes) dont vous avez besoin, puis d'utiliser le Client ID et le Client Secret de cette application pour vous connecter au serveur MCP. Une application non publiée et non interne est refusée par Slack.

Exemple de déclaration pour un client compatible (adaptez selon la syntaxe exacte de votre outil) :

{ "name": "Slack (officiel)", "transport": "http", "url": "https://mcp.slack.com/mcp" }

Authentification

OAuth confidentiel, via l'application Slack que vous créez (Client ID / Client Secret), avec les scopes utilisateur nécessaires aux outils que vous souhaitez utiliser.

Le premier serveur MCP de référence d'Anthropic pour Slack a été retiré en 2025 après la découverte d'une faille de sécurité, avant que Slack ne publie sa propre version officielle. Un standard ouvert et récent ne veut pas dire que chaque implémentation est sûre : c'est la maintenance et l'audit qui font la différence.

slack.com/help — Guide to Model Context Protocol in Slack

FAQ

Pourquoi Slack demande-t-il de créer une application avant de se connecter ?

Slack restreint le MCP aux applications publiées sur le Slack Marketplace ou internes à votre organisation, pour garder le contrôle sur les permissions accordées à un agent IA dans un espace de travail.

Le connecteur Slack MCP est-il le même qu'avant 2026 ?

Non : il remplace l'ancien serveur de référence d'Anthropic, retiré en 2025 après une faille de sécurité. C'est désormais un serveur officiel publié directement par Slack.

Une application Slack interne suffit-elle, ou faut-il la publier sur le Marketplace ?

Une application interne à votre organisation suffit ; la publication sur le Slack Marketplace n'est nécessaire que si vous voulez la rendre disponible à d'autres organisations.
