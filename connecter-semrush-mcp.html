Librairie MCP Marketing

Connecter Semrush en MCP à Claude ou ChatGPT

Semrush héberge son propre serveur MCP officiel : aucune installation locale, juste une URL à ajouter dans les réglages de votre assistant IA. Voici comment faire.

Semrush est l'un des premiers éditeurs SEO à avoir publié un serveur MCP officiel entièrement hébergé : analyses de mots-clés, de domaines et de backlinks directement en conversation, sans quitter votre assistant IA.

Comment se connecter

URL du serveur (v2, celle indiquée dans la documentation officielle pour les clients récents) :

https://mcp.semrush.com/v2/mcp

Avec Claude Code (ligne de commande) :

claude mcp add semrush https://mcp.semrush.com/v2/mcp -t http

Avec un client à interface graphique (Claude.ai, ChatGPT...) : dans les réglages de connecteurs, ajoutez un connecteur personnalisé et collez cette URL.

Une version v1 (https://mcp.semrush.com/v1/mcp) existe aussi dans la documentation ; vérifiez sur la doc officielle laquelle correspond à votre client au moment de la connexion, les éditeurs migrent parfois leurs clients vers la dernière version disponible.

Authentification

OAuth 2.1 par défaut (connexion à votre compte Semrush). Une clé d'API est proposée en alternative pour les clients qui ne gèrent pas OAuth. Nécessite un abonnement Semrush payant avec des unités d'API disponibles.

Documentation officielle

semrush.com/mcp · developer.semrush.com

FAQ

Le connecteur Semrush MCP est-il inclus dans tous les abonnements ?

Non, il nécessite un abonnement Semrush payant avec des unités d'API disponibles — vérifiez votre forfait sur la documentation officielle.

Dois-je choisir entre la v1 et la v2 de l'URL du serveur ?

La v2 est celle indiquée pour les clients récents dans la commande Claude Code officielle ; la v1 reste documentée. En cas de doute, la documentation officielle liée ci-dessus fait foi.

Une clé API est-elle obligatoire ?

Non, OAuth 2.1 est le mode par défaut. La clé API est une alternative pour les clients qui ne gèrent pas OAuth.
