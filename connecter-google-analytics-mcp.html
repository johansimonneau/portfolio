Librairie MCP Marketing

Connecter Google Analytics (GA4) en MCP à Claude ou ChatGPT

Google publie un serveur MCP officiel pour Google Analytics : de quoi interroger vos rapports GA4 en langage naturel, sans export CSV. Voici comment l'installer et le connecter.

Le serveur MCP officiel de Google Analytics permet à un assistant IA compatible (Claude, ChatGPT, Cursor...) de lire directement vos comptes, propriétés et rapports GA4 : funnels, temps réel, rapports standards, en langage naturel plutôt qu'en export manuel.

Comment se connecter

Le serveur est distribué sous forme de paquet Python analytics-mcp, à lancer avec pipx (ou uvx) :

pipx run analytics-mcp

Pour l'ajouter à Claude Code (l'outil en ligne de commande) :

claude mcp add analytics-mcp

Le dépôt officiel documente aussi une configuration pour d'autres clients (dont Gemini CLI). Les options exactes — variables d'environnement à transmettre, arguments optionnels — sont détaillées dans le README officiel, à consulter avant l'installation.

Authentification

OAuth via les identifiants applicatifs par défaut de Google (Application Default Credentials), avec une portée en lecture seule (analytics.readonly). Variable d'environnement à renseigner : GOOGLE_APPLICATION_CREDENTIALS (chemin vers votre fichier d'identifiants). L'usurpation d'identité par compte de service est possible en option.

Documentation officielle

github.com/googleanalytics/google-analytics-mcp

FAQ

Ce connecteur peut-il écrire dans mon compte Google Analytics ?

Non, il est documenté en lecture seule (portée analytics.readonly) : il peut consulter vos rapports mais pas modifier la configuration de votre compte.

Faut-il un compte Google Cloud pour l'utiliser ?

L'authentification passe par les identifiants applicatifs par défaut de Google, ce qui suppose un projet Google Cloud pour générer ces identifiants — la documentation officielle détaille la marche à suivre.

Ce connecteur fonctionne-t-il avec Universal Analytics (l'ancien GA) ?

Non, il est conçu pour Google Analytics 4 (GA4), la version actuelle de Google Analytics.
