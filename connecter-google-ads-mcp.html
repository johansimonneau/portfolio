Librairie MCP Marketing

Connecter Google Ads en MCP à Claude ou ChatGPT

Google publie un serveur MCP officiel open source pour Google Ads, pensé pour l'analyse de comptes et de rapports plutôt que pour piloter des campagnes à l'aveugle. Voici comment l'installer.

Le serveur MCP officiel de Google Ads permet d'interroger vos comptes, vos rapports GAQL et vos métadonnées de campagnes en langage naturel, avec un accent mis sur l'analyse plutôt que sur le pilotage automatique des enchères.

Comment se connecter

Paquet Python officiel google-ads-mcp, lancé via pipx :

pipx run --spec "google-ads-mcp==X.Y.Z" google-ads-mcp

(remplacez X.Y.Z par le numéro de version indiqué dans la documentation officielle)

Configuration (format mcpServers) :

{
  "mcpServers": {
    "google-ads-mcp": {
      "command": "pipx",
      "args": ["run", "--spec", "git+https://github.com/googleads/google-ads-mcp.git", "google-ads-mcp"],
      "env": { "GOOGLE_APPLICATION_CREDENTIALS": "CHEMIN_VERS_VOS_IDENTIFIANTS.json" }
    }
  }
}

Un déploiement sur Google Cloud Run est aussi documenté officiellement, pour un usage partagé par une équipe plutôt qu'en local.

Authentification

Identifiants applicatifs par défaut de Google (Application Default Credentials), ou fichier google-ads.yaml du client API Google Ads. Un jeton développeur (developer token) est nécessaire pour un accès en production.

Documentation officielle

github.com/googleads/google-ads-mcp

FAQ

Ce connecteur peut-il modifier mes campagnes Google Ads ?

Le serveur est pensé pour l'analyse (comptes, rapports GAQL, métadonnées) plutôt que pour piloter des actions — reportez-vous à la documentation officielle pour le détail exact des permissions disponibles.

Faut-il un jeton développeur Google Ads pour l'utiliser ?

Oui pour un accès en production, un jeton développeur (developer token) est nécessaire en plus de l'authentification par identifiants applicatifs par défaut.

Peut-on l'héberger ailleurs qu'en local ?

Oui, un déploiement sur Google Cloud Run est documenté officiellement pour un usage partagé par une équipe plutôt qu'une installation locale individuelle.
