Librairie MCP Marketing

Connecter Microsoft Advertising en MCP

Microsoft héberge désormais son propre serveur MCP officiel pour Microsoft Advertising (ex-Bing Ads), avec une authentification Microsoft Entra ID et un support documenté pour Claude, ChatGPT, Copilot Studio et GitHub Copilot. Voici comment l'ajouter.

Le serveur MCP officiel de Microsoft Advertising donne accès à vos campagnes et comptes Microsoft Advertising directement depuis un assistant IA compatible, sans installation locale.

Microsoft

Comment se connecter

URL du serveur officiel, identique pour tous les clients IA :

https://partner.api.bingads.microsoft.com/ext/mcp/vnext

Pour Claude : dans Réglages > Connecteurs > Ajouter > Ajouter un connecteur personnalisé, collez cette URL, puis sous Authentification choisissez de vous connecter avec votre propre client OAuth (identifiant client obtenu via une inscription d'application Microsoft Entra ID, documentée par Microsoft avec Azure CLI). Le même serveur est aussi documenté pour Copilot Studio, GitHub Copilot dans VS Code et ChatGPT.

Authentification

Connexion par OAuth via Microsoft Entra ID (anciennement Azure Active Directory), avec prise en charge des comptes professionnels/scolaires (AAD) et des comptes Microsoft personnels. L'autorisation Microsoft Advertising est distincte de votre compte Claude ou ChatGPT : elle ne donne accès qu'aux comptes et clients Microsoft Advertising déjà accessibles au compte Microsoft utilisé pour l'autoriser.

Documentation officielle

learn.microsoft.com

FAQ

Faut-il un compte Azure payant pour utiliser ce connecteur ?

Non : l'inscription de l'application OAuth se fait via Azure CLI, mais aucun abonnement Azure n'est nécessaire (une connexion avec l'option --allow-no-subscription est documentée par Microsoft). Un compte Microsoft Entra ID ou un compte Microsoft personnel donnant accès à votre compte Microsoft Advertising suffit ensuite.

Quels assistants IA sont compatibles avec ce connecteur ?

Microsoft documente la connexion pour Copilot Studio, GitHub Copilot dans VS Code, ChatGPT (plans Plus, Pro, Business, Enterprise, Edu) et Claude (Free, Pro, Max, Team, Enterprise).

L'autorisation Microsoft Advertising est-elle liée à mon compte Claude ou ChatGPT ?

Non, la documentation officielle précise que l'autorisation Microsoft Advertising (via Entra ID ou compte Microsoft personnel) est distincte de la connexion à votre compte Claude, ChatGPT ou de votre organisation sur ces outils.
