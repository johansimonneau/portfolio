Connecter Figma en MCP

Figma héberge désormais un serveur MCP distant disponible sur tous les plans, en plus du serveur local en Dev Mode réservé à des cas d'usage entreprises. Voici comment connecter le premier.

Le serveur MCP officiel de Figma donne à un assistant IA le contexte d'une maquette (composants, variables, auto-layout) pour générer du code fidèle au design, capturer une interface web vers Figma, ou écrire directement dans un fichier Figma.

Comment se connecter (serveur distant, recommandé)

URL du serveur hébergé par Figma :

https://mcp.figma.com/mcp

Dans un fichier Figma Design ouvert dans le navigateur, passez en Dev Mode sans rien sélectionner sur le canvas, puis cliquez sur « Set up an MCP client » dans le panneau d'inspection. Avec Claude Code (ligne de commande) :

claude plugin install figma@claude-plugins-official

Disponible sur tous les sièges et toutes les formules Figma : aucune licence payante n'est requise pour ce serveur distant.

Option entreprise : serveur local (Dev Mode, application de bureau)

Figma réserve désormais le serveur local de bureau à des cas d'usage spécifiques côté entreprises ; pour la plupart des usages, le serveur distant ci-dessus couvre un périmètre plus large. Il nécessite un siège Dev ou Full sur une formule payante, et l'application de bureau Figma ouverte :

http://127.0.0.1:3845/mcp

Authentification

OAuth avec votre compte Figma pour le serveur distant : la première connexion ouvre une fenêtre d'autorisation (« Allow access »), réutilisée ensuite pour les sessions suivantes. Le serveur local ne demande aucune authentification séparée : l'accès dépend uniquement du fait d'être connecté à l'application de bureau avec un accès Dev Mode.

Documentation officielle

help.figma.com — Figma remote MCP server · developers.figma.com/docs/figma-mcp-server (serveur local)

FAQ

Faut-il un abonnement Figma payant pour utiliser le serveur distant ?

Non, Figma indique que le serveur distant est disponible sur tous les sièges et toutes les formules. C'est le serveur de bureau (Dev Mode) qui reste réservé aux sièges Dev ou Full des formules payantes.

Faut-il encore utiliser le serveur de bureau (Dev Mode) ?

Figma le réserve désormais à des cas d'usage spécifiques côté entreprises. Pour l'essentiel des usages, le serveur distant couvre un périmètre de fonctionnalités plus large.

Comment s'authentifie-t-on sur le serveur distant ?

Par OAuth avec votre compte Figma : la première connexion ouvre une fenêtre d'autorisation, réutilisée ensuite pour les sessions suivantes.
