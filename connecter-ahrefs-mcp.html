Librairie MCP Marketing

Connecter Ahrefs en MCP à Claude ou ChatGPT

Ahrefs publie un serveur MCP officiel pour interroger son index de backlinks et de mots-clés directement en conversation. Voici comment l'installer.

Le serveur MCP officiel d'Ahrefs donne accès à ses données de backlinks et de mots-clés directement depuis un assistant IA, sans passer par l'interface web à chaque requête.

Statut & type de connexion

Éditeur
Ahrefs
Statut
Officiel
Connexion
Locale (commande)

Comment se connecter

Installation du paquet npm officiel :

npm install --prefix=~/.global-node-modules @ahrefs/mcp -g

Configuration (format mcpServers, compatible avec la plupart des clients MCP) :

{
  "mcpServers": {
    "ahrefs": {
      "command": "npx",
      "args": ["--prefix=~/.global-node-modules", "@ahrefs/mcp"],
      "env": { "API_KEY": "VOTRE_CLE_API" }
    }
  }
}

Remarque importante : le dépôt officiel de ce serveur local est aujourd'hui archivé, avec une mention indiquant qu'un serveur distant le remplace désormais. L'URL exacte de ce serveur distant n'est pas confirmée dans ce dépôt au moment de la rédaction — vérifiez la documentation officielle Ahrefs avant de choisir entre l'installation locale ci-dessus et un éventuel serveur distant plus récent.

Authentification

Clé d'API Ahrefs (API v3), à renseigner dans la variable d'environnement API_KEY. Ne partagez jamais cette clé dans un dépôt public ou un outil collectif non sécurisé.

Documentation officielle

github.com/ahrefs/ahrefs-mcp-server

FAQ

Le serveur Ahrefs local est-il encore recommandé ?

Le dépôt officiel est archivé et indique qu'un serveur distant le remplace désormais, sans en préciser l'URL exacte à ce jour. Vérifiez la documentation officielle avant de choisir.

Faut-il un abonnement Ahrefs spécifique pour la clé API ?

Oui, l'accès à l'API Ahrefs (et donc à ce connecteur) dépend de votre forfait Ahrefs — vérifiez votre accès API sur votre compte.

Cette configuration fonctionne-t-elle avec Claude Desktop ?

Le format mcpServers ci-dessus est compatible avec la plupart des clients MCP qui lisent ce type de configuration, dont Claude Desktop.
